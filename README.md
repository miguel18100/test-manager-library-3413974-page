# Manager Library · Page

Sitio público de presentación del producto. Es **estático**: un solo `index.html`, sin llamadas a la
API, sin dependencias externas (tipografía del sistema, iconos en SVG en línea) y adaptable a móvil
y escritorio (`viewport`, `@media` y rejillas que se ajustan al ancho).

## Ver el sitio

Abre `index.html` en el navegador, o publícalo tal cual (GitHub Pages, Netlify, cualquier servidor
de archivos). No necesita la API ni un paso de compilación.

## Qué presenta

Catálogo, categorías, socios, préstamos, devoluciones, libros vencidos, reglas del préstamo,
reporte de más prestados y roles.
